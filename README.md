**Installation Instructions:**
1. First download the mod manager. [NOMM](https://github.com/Combat787/NOMM/releases/download/5.4.0/nomm-5.4.0-win-x64.msi)
2. Run the mod manager.
3. Import the latest version of the modpack located here. [Latest Release](https://github.com/BennyBoi233/Nuclear-Option-Main-Modpack/releases/latest)
4. Update all mods.
5. Press the play button.
